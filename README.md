# Rushd Studio Tracker — Sesi 8 (branch: main)

Aplikasi pencatatan Klien, Proyek, dan Invoice dengan **Firebase Realtime Database**.

- CRUD lengkap untuk 3 entitas (12 fungsi) yang tersambung ke Realtime Database.
- Form HTML untuk tiap operasi, dengan CSS.
- Belum ada login (ditambahkan di Sesi 9).

Isi `js/firebase-config.js` dengan config project Firebase-mu, lalu jalankan `python3 -m http.server 8080` dan buka http://localhost:8080.
